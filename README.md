# Token Radar — pre-token protocols ranked by implied value

Entry for the make.fun bounty **[Build the best token launch radar](https://make.fun/bounty/token-radar-01)** ($1,325 in prizes, closes 14 Dec 2026 17:00 WIB).

It reads a sealed snapshot of every protocol DefiLlama tracks, works out which ones still
record no token and are not a wrapped or staked product of one that trades, ranks them by what
their launch would be worth, and hands in a web dashboard with the board, a detail view for
each protocol and the steps to farm it.

## What it finds

- **758 protocols** in the snapshot (DefiLlama, fetched 2026-11-14), **40 on the watchlist**
  (TVL ≥ $50M, no token on record, not a wrapped/staked/bridged product).
- **226 rows scored**: the whole watchlist plus **186 early-radar rows** — every other
  rankable pre-token protocol below the floor, by TVL.
- **24 live-token protocols set aside**, shown with their market caps: they are the
  comparables, never mixed into the ranking.
- Total implied value across the board: **≈ $5.14B**. Rank #1 is Steakhouse Financial
  (≈ $1.38B implied on $2.75B TVL).

## The model (radar-2-comps)

A flat multiple would price a lending protocol like a bridge. This model prices each
category off the live-token protocols that already trade in it, using only the snapshot:

```
multiple = clamp((n × median(mcap/TVL in category) + 6 × 0.246) / (n + 6), 0.03, 1.5)
implied  = round( tvl × multiple × (1 + clamp(change_7d, −60, 120)/100 × 0.5)
                  × (0.6 + min(age_days, 1095)/1095 × 0.4) )
```

- **Comparables**: per category, the median market-cap-over-TVL of live-token protocols
  (market-wide median 0.246x; 33 categories priced). Thin categories are shrunk toward the
  market median (weight 6); every multiple is clamped to 0.03–1.5x, inside the range the
  live market shows.
- **Growth**: the 7-day TVL change, clamped to −60…+120%, half weight.
- **Maturity**: age since first listing, 0.6–1.0 over three years (unknown age = 365 days).
- No protocol name is special-cased; the same function scores every row, and the dashboard
  shows each row's multiple, its comparables and the full arithmetic.

## The dashboard

`dashboard/` is a static page (no framework, no network — all data ships in `data.js`):

- **Board**: all 226 rows, sortable, with TVL, 7-day growth, age, category multiple and
  implied value; spotlight cards for the top 5; implied value by category.
- **Detail view**: click any row — valuation waterfall, live-token comparables in its
  category, a six-step farm plan (capital, cost and time per step) and risk notes.
- **Filters**: search, category, chain, watchlist-only; tabs for pre-token, live-token and
  the comparables table with the full methodology.
- **Deep links**: `#p=<slug>`, `#category=`, `#chain=`, `#q=`, `#tab=` — the screenshots
  use them.

## Run it

Requires Node.js 22.18+ (the repo runs on Node 24 here; no dependencies, no install).

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ./snapshot.json
# writes out/board.json, out/data.js, out/dashboard/, out/screenshots/, out/dossier.json
```

`main.ts` reads the snapshot (default `/input/snapshot.json`, the sealed mount), builds the
board with `lib/model.ts`, copies `dashboard/` and `screenshots/`, and writes
`dossier.json` with the vendored `vendor/makefun-board.ts` (copied byte-for-byte from the
kit; the scorer rebuilds the dossier from the same file and compares bytes).

Screenshots are taken headlessly with Playwright (`scripts/screenshot.mjs`, 1440×900):
`1-board.png` (the board), `2-detail.png` (rank #1's detail view), `3-filtered.png`
(category filter). Re-run `main.ts` after taking them so `out/` and `dossier.json` match.

## Layout

```
main.ts                  entrypoint: snapshot in, board + dashboard + dossier out
lib/model.ts             the comps-calibrated model, the board, the farm plans
vendor/makefun-board.ts  make.fun's dossier library, copied from the kit, unchanged
dashboard/               index.html, app.css, app.js — the static page (no network)
screenshots/             1-board, 2-detail, 3-filtered
board.json               the ranked board (226 rows; regenerated by main.ts)
dossier.json             the judge's dossier (regenerated by main.ts)
scripts/screenshot.mjs   headless-Chromium screenshot script
session.md               build log (transcript)
makefun-run.json         structured run record (transcript)
```
